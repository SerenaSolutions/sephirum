## 1. Where hashtags do and do not work

- GitHub has NO hashtags. Discovery inside GitHub happens through
  repo topics (15 already set), the language bar, and trending
  (driven by stars/forks/activity — cannot be bought, only earned).
- Hashtags work on X, LinkedIn, Bluesky, Instagram. Reddit and
  Hacker News have NO hashtags — there the post text itself does
  the work.
- Hashtag set (use together, always the same three):
  `#ZEPHIRUM #ZYQL #QuantumComputing`
  (secondary: `#ProgrammingLanguages`, `#ProofCarryingCode`)
- Rules of honesty: never buy stars, never mass-mention people,
  never astroturf. Evidence-first is the brand; spam would kill it
  faster than silence.
