# Security Policy

## Scope
The language core (`src/`, `prototype/`), the multi-target transpiler and
the plugin. Hardware execution is always gated by exact-verdict certificates;
failures of that gate are security-relevant.

## Reporting
Use GitHub's private security advisory
(Report a vulnerability in the Security tab), or open an issue marked
**security** if advisories are unavailable. Please include the minimal
`ASK/CONTRACT/MODEL` source. Do not open public issues for
exploitable details.
